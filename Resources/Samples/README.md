# Sample media

Orbit.mp4 and Tidal.mp4 are original, silent, 24-second procedural motion studies generated by Scripts/GenerateSamples.swift. They are covered by this repository’s MIT license. They contain no third-party footage, voices, photographs, or music.

The separate Apple HLS example is streamed directly from Apple’s developer CDN only when selected; it is not bundled or relicensed here. See https://developer.apple.com/streaming/examples/ for its source and testing purpose.
