# Contributing

Use Xcode 27 and Swift 6. Keep playback explicitly initiated, retain native AVKit controls, preserve semantic fonts and focus navigation, and bound persisted state. Never add media without clear provenance and distribution rights.

Run core tests in Debug and Release, build the simulator and unsigned device target, and exercise navigation with XCUIRemote. Verify subtitles, interruptions, text sizes, and physical remote behavior on Apple TV. Keep signing identities, build output, and personal media out of commits.

Use focused Conventional Commits with honest verification notes.
